# About

I build MERN apps with AI features (Pollinations AI) and work with AI agents, prompt engineering and workflow automation. I ship features quickly with AI-assisted development (GitHub Copilot, Cursor), code review and rapid prototyping.

My projects include a car rental platform with customer booking and owner workflows, a real-time chat application using Socket.IO, and an AI thumbnail generator. These projects have given me experience with authentication, REST APIs, image handling, and turning an idea into a working application. I also contributed to full-stack website projects during internships at CSIR-NISTADS and AIIMS Bhopal.

I’m looking for a full-stack development role where I can contribute to both frontend and backend work, learn from experienced engineers, and build software that people find useful.
